# Employee-Management-System-ABAP
Employee Management System with Insert, Display, Search, Update, Delete and ALV Report functionalities.

SAP ABAP Employee Management System

Project Overview

The Employee Management System is a beginner-level SAP ABAP on HANA project developed to manage employee information using database operations and ALV reporting.

The project allows users to insert, display, search, update and delete employee records.

Technologies Used

- SAP ABAP on HANA
- SAP GUI
- ABAP Dictionary (SE11)
- Open SQL
- ALV Grid Display

Database Table

Table Name: "YEMP_DETAILS"

Employee fields:

- Employee ID
- Employee Name
- Department
- City
- Salary

Project Functionalities

1. Insert Employee Records
2. Display Employee Records
3. Search Employee by ID
4. Update Employee Details
5. Delete Employee Records
6. ALV Grid Report using "REUSE_ALV_GRID_DISPLAY"
7. Duplicate Employee ID Validation
8. Mandatory Field Validation
9. Salary Validation

ABAP Programs

- "ZEMP_INSERTS" – Insert employee records
- "ZEMP_DISPLAY" – Display employee records
- "ZEMP_SEARCH" – Search employee records
- "ZEMP_UPDATE" – Update employee records
- "ZEMP_DELETE" – Delete employee records
- "ZEMP_ALV" – Display employee data using ALV Grid

Learning Outcomes

- Practical understanding of ABAP CRUD operations
- Working with custom database tables
- Using Open SQL statements
- Implementing input validations
- Creating ALV reports

Project Status

Completed and tested as a beginner-level SAP ABAP learning project.
